# Képtár

Showcase of contemporary Hungarian visual artists. Next.js + Payload CMS 3.

```sh
cp .env.example .env   # then set PAYLOAD_SECRET
pnpm install
pnpm seed
pnpm dev               # http://localhost:3000, admin at /admin
```

See `CLAUDE.md` for commands, schema and conventions, and `docs/PLAN.md` for the plan.
